Installing it

  1. Tap Download above on the Android phone you want it on.
  2. Open the file when it finishes. Android will ask whether to allow installs from your browser — this is normal for an app that does not come from the Play Store. Say yes.
  3. Open CineVerse and sign in with the same account you use on the web. Your list, your watched history and every episode you have ticked are already there.
Updates look after themselves. CineVerse checks GitHub a few times a day and offers you the new version with release notes and a progress bar. You never have to come back to this page.

What it does

Everything, syncedThe same account and the same data as CineVerse on the web, live in both directions.
One-tap episodesTick an episode from the app, or from a home-screen widget without opening it.
Real ratingsIMDb, the Tomatometer and Metacritic beside CineVerse's own score.
Works offlineYour whole library and everything you have opened, on a plane.

Is this safe?

  • Every release is built by GitHub Actions from the source in this repository — nobody uploads an APK by hand.
  • Each release publishes the APK's SHA-256, and the app checks it before installing an update.
  • It asks for four permissions: internet, network state, vibration, and permission to install its own updates.
